# MEDIBUDDY 3.0

Assamese-inspired medication and personal wellness dashboard.

## Features
- Flask + SQLite medication manager (add, edit, delete)
- Today's medication schedule and taken/skipped records
- Stock count and low-stock overview
- Wellness timer, daily activity goal, 7-day activity chart
- Personal reflection notes and local activity history
- English, Assamese and Hindi interface labels
- Responsive layout; no camera or camera dependencies

## Run on Windows
See `SETUP_WINDOWS.txt`.

## Data storage
Medication records are stored in `data/medibuddy.db`.
Wellness activity and reflection data are stored in the browser's local storage.
This is a personal tracking application, not a medical device or medical advice service.
