MEDIBUDDY 3.0 — WINDOWS SETUP

1. Extract MEDIBUDDY_3.zip to a new folder, for example:
   C:\Users\YOURNAME\Desktop\MEDIBUDDY_3

2. Open PowerShell and run (edit the path if you extracted elsewhere):

   cd "$env:USERPROFILE\Desktop\MEDIBUDDY_3\backend"

3. Create a virtual environment:

   py -3.10 -m venv venv

   If Python 3.10 is not installed, use:
   python -m venv venv

4. Activate it:

   .\venv\Scripts\Activate.ps1

   If PowerShell blocks activation, run this once in that terminal:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\venv\Scripts\Activate.ps1

5. Install requirements:

   python -m pip install --upgrade pip
   pip install -r requirements.txt

6. Start the application:

   python app.py

7. Open this address in your browser:

   http://127.0.0.1:5000

To stop the server, press Ctrl+C in PowerShell.

IMPORTANT:
- This is a NEW independent project and creates its own database at data\medibuddy.db.
- Your old mediibro folder and old database are not changed.
- Wellness activity and journal records are stored in the browser on this computer.
- Do not use this app to decide doses or change prescribed medication. Follow your clinician's instructions.
